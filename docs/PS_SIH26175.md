# SIH26175 — requirements checklist

Source: SIH 2026 problem-statement page (sih.gov.in, PS 26175, ISRO / SAC) and ISRO's reference repo
(github.com/IMG-PROCESS-SAC/SIH2026), read 2026-09-19. Paraphrased; see the sources for the full text.

| Requirement (from the PS) | Where it is met |
|---|---|
| PNG/JPG (no spatial metadata) → **relative DSM (rDSM)** | `pipeline.process`, non-georeferenced branch; labelled RELATIVE in files and viewer |
| GeoTIFF → **absolute DSM with metric heights** | FABDEM terrain + predicted nDSM, written in the image's (metric) CRS |
| Use a **pre-trained monocular depth-estimation backbone** | Depth Anything V2 (DINOv2 + DPT) pre-trained weights, fine-tuned on GAMUS |
| **Scale calibration** via scene statistics / low-res DEM / semantic priors / minimal GCPs | metric nDSM head (trained on LiDAR heights) + 30 m bare-earth DEM + robust GCP plane fit |
| Project the optical image onto a 3D terrain mesh, in Three.js / Babylon / Unity | Three.js viewer, texture draped on the metric mesh |
| **First-person navigation**; analysis of **structural heights and slopes** from any aerial view | Fly mode (WASD + mouse), orbit, tour; height probe, slope overlay, height profile |
| Standalone deployable unified module, source + docs | `pip install .` → `depthwizard`; README, docs/ |
| Upload imagery; **validate heights against reference datasets** | upload page with optional reference DSM; error overlay, swipe compare, RMSE/MAE/corr panel |
| Output DSM in a **standard geospatial format** | Cloud-friendly tiled GeoTIFF (float32, deflate), CRS + transform preserved |

## Evaluation (as stated)

- **DSM accuracy and validation — 50 %**: RMSE, MAE and correlation against LiDAR or reference data, *including stability across urban, sparse, hilly and forested landscapes*.
- **Visualization and UX — 50 %**: projection accuracy, visual fidelity, navigability of the 3D flythrough, interface intuitiveness, software stability, standalone deployment.

No error threshold is given; ranking is relative. Final evaluation uses ISRO RGB imagery.
